# Light Implementation Plan

> **For agentic workers:** Execute this plan step-by-step. Steps use checkbox (`- [ ]`) syntax. At each "CHECKPOINT" marker, run the full checkpoint protocol (§Checkpoint Protocol) before proceeding.

**Goal:** A Go-idiomatic port of Hugging Face Candle that runs complex ML models (LLaMA, BERT, Whisper, Stable Diffusion, etc.) on CUDA GPUs and CPUs with full feature parity and >80% test coverage.

**Architecture:** Layered: `dtype` → `shape` → `device` → `storage` → `tensor` → `ops` → `nn`/`transformers` → `models`. CUDA is a build-tag-gated backend using cuBLAS + cuDNN + vendored Candle `.cu` kernels compiled to PTX (JIT'd by the driver at first use). Autograd is PyTorch-style define-by-run with `FunctionNode` DAG.

**Tech Stack:** Go 1.26 (generics, `runtime.AddCleanup`), CGo, CUDA ≥12, cuBLAS, cuBLASLt, cuDNN, nvcc (build-time), nvrtc (optional runtime path), vendored Candle kernels.

**Design reference:** `docs/design/2026-04-17-design.md`.

---

## Policies (apply to every step)

- **TDD.** Write failing test → run and confirm failure → implement minimum → run and confirm pass.
- **No git.** `CHECKPOINTS.md` (root) is the progress log. Append one line per completed step: `YYYY-MM-DD HH:MM | <step-id> | <short result>`. No `git commit` anywhere.
- **Package docs.** Every new package gets a `doc.go` with a one-paragraph summary.
- **File size.** Target <500 lines per file; split when natural.
- **Dtype dispatch.** Internal functions that must handle multiple dtypes use the `DType` runtime enum; user-facing leaves use Go generics `[T Numeric]`.
- **No silent fallback.** Every example calls `device.MustCUDA()` or similar explicit assertion when it claims to be GPU.
- **Vendored upstream code.** Anything copied from Candle (any path) must retain its upstream copyright header. `NOTICE` lists every upstream file.
- **Error returns.** Public APIs return `(*T, error)` or `error`. No panics in library code.
- **One direction.** Higher layers import lower; never the other way.

---

## Checkpoint Protocol

Run after every step labelled **CHECKPOINT**. All must pass, or the step is not done:

1. **Compiles both tags.**
   - `go build ./...` (CPU-only)
   - `go build -tags cuda ./...` (CUDA)
2. **Tests pass both tags.**
   - `go test ./... -count=1`
   - `go test -tags cuda ./... -count=1`
3. **Coverage ≥80% for touched packages.**
   - `go test -cover ./...` — parse output, fail if any touched package <80%.
   - `scripts/coverage.sh` enforces this (written in Phase 0 step 0.8).
4. **Examples built in this step run successfully.**
   - For GPU examples: `go run -tags cuda ./examples/<name>` — must print `device=CUDA(ordinal=0)` at startup (no silent CPU fallback).
   - For CPU examples: `go run ./examples/<name>`.
5. **Feature tracker updated.** `FEATURES.md` has the newly completed items ticked.
6. **Checkpoint log entry** appended to `CHECKPOINTS.md`.

If a checkpoint fails, **do not proceed**. Fix the failure first, then re-run the full protocol.
